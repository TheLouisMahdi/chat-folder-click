# Chat Folder Click | راهنمای فارسی

**افزونه‌ای سبک برای انتخاب پوشه، مدیریت فایل‌های محلی و ارتباط اختیاری با ChatGPT در Microsoft Edge.**

## این افزونه چه کاری انجام می‌دهد؟

با انتخاب یک پوشه از طریق رابط گرافیکی Edge می‌توانی ساختار پوشه‌ها را به‌شکل درختی ببینی، فایل‌های متنی را بخوانی و ویرایش کنی، فایل یا پوشه جدید بسازی و فایل‌ها را وارد یا دانلود کنی. محیط سه تم **White / Black / Terminal** دارد.

بخش **Chat link** می‌تواند درخواست‌های ساختاریافته در پاسخ ChatGPT را تشخیص دهد و پس از تأیید تو، عملیاتی مانند خواندن یا ویرایش فایل را در پوشه انتخاب‌شده انجام دهد. نتیجه واقعی را می‌توانی به گفتگو برگردانی.

**توجه:** مدل ChatGPT دسترسی مستقیم و بومی به دیسک ندارد. افزونه واسطه‌ای در صفحه مرورگر است. اگر تشخیص خودکار پیام کار نکرد، امکان کپی درخواست JSON در بخش **Activity** وجود دارد.

## نصب در Microsoft Edge بدون خط فرمان

### نصب از ZIP نسخهٔ منتشرشده

1. صفحهٔ [نسخه‌ها در GitHub](https://github.com/TheLouisMahdi/chat-folder-click/releases) را باز کن. پس از انتشار v2.1.0، فایل **`chat-folder-click-edge-v2.1.0.zip`** را از بخش **Assets** بگیر. اگر هنوز نسخه‌ای منتشر نشده، از روش ZIP سورس در پایین استفاده کن.
2. با **Extract All** فایل را استخراج کن. پوشهٔ استخراج‌شده را در محل ثابتی نگه دار؛ Edge افزونه را از همان پوشه بارگذاری می‌کند.
3. در Edge به آدرس `edge://extensions` برو، **Developer mode** را روشن کن و روی **Load unpacked** بزن.
4. پوشه‌ای را انتخاب کن که فایل **`manifest.json` مستقیماً داخل آن است**. ZIP افزونه زیرپوشهٔ `extension` ندارد؛ خود فایل ZIP را انتخاب نکن.
5. از منوی افزونه‌های Edge روی **Chat Folder Click** بزن تا پنل کناری باز شود. در صورت تمایل آیکون آن را پین کن.

### نصب از ZIP سورس

در [صفحهٔ مخزن](https://github.com/TheLouisMahdi/chat-folder-click) گزینهٔ **Code > Download ZIP** را بزن و با **Extract All** استخراج کن. مراحل ۳ تا ۵ بالا را انجام بده، اما این بار **زیرپوشهٔ `extension`** را در پوشهٔ استخراج‌شدهٔ مخزن انتخاب کن. فایل **Source code (zip)** در صفحهٔ نسخه‌ها نیز همین ساختار را دارد.

برای استفاده از امکانات معمول فایل‌منیجر، نصب Node.js، سرور، Proxy، API Key یا دستور PowerShell لازم نیست.

## شیوه کار با فایل‌ها

1. در پنل روی **Choose folder** بزن، پوشهٔ محلی را انتخاب کن و مجوز دسترسی بده. برای شروع، از یک پوشهٔ آزمایشی شامل فایل `notes.txt` استفاده کن.
2. در تب **Explorer** پوشه‌ها را باز و یک فایل متنی UTF-8 را انتخاب کن. پس از ویرایش، روی **Review & save** بزن، پیش‌نمایش تغییرات را بررسی کن و با **Apply changes** روی دیسک ذخیره کن.
3. برای ساخت فایل یا پوشه از **New file** / **New folder**، برای ورود فایل از **Import files** و برای دانلود از **Download file** استفاده کن. برای تغییر پروژه دوباره **Choose folder** را بزن؛ اگر دسترسی پوشهٔ قبلی منقضی شد، **Grant access** را انتخاب کن.
4. تم **White**، **Black** یا **Terminal** را از بالای پنل انتخاب کن. از فایل‌های مهم بکاپ بگیر؛ Undo فقط برای بعضی تغییرات اخیر و تا وقتی پنل باز است در دسترس است.

جزئیات بیشتر و رفع اشکال در [راهنمای کامل استفاده](docs/USAGE.md) آمده است.

## شیوه کار با ChatGPT

1. صفحهٔ `https://chatgpt.com` را در Edge باز کن.
2. در تب **Chat link** روی **Prepare ChatGPT** بزن، متن آماده‌شده را بررسی کن و خودت ارسال کن.
3. مدل یک درخواست مانند نمونه زیر می‌دهد:

```json
{"bridge":"chat-folder-click","action":"read","path":"README.md"}
```

4. مسیر باید در پوشهٔ انتخاب‌شده وجود داشته باشد؛ برای نمونهٔ بالا، آن پوشه باید فایل `README.md` داشته باشد. روی **Review in folder** بزن؛ اگر این دکمه نبود، JSON را در **Activity > Manual fallback** قرار بده و **Queue JSON request** را بزن.
5. در **Activity** مسیر و نوع درخواست را بررسی کن، **Review & execute** را بزن و عملیات را تأیید کن. نتیجهٔ واقعی را در **Last operation** ببین؛ سپس با **Return to ChatGPT** پیش‌نویس آن را به چت برگردان و خودت **Send** را بزن.

فایل‌های حساس مانند `.env` و کلیدهای خصوصی را به گفتگو ارسال نکن. درخواست‌های مدل را بدون بررسی تأیید نکن.

## محدودیت‌ها

- اجرای ترمینال، Git CLI، Build و تست برنامه در این افزونه مرورگری پشتیبانی نمی‌شود.
- ویرایشگر مخصوص فایل متنی UTF-8 تا سقف ۲ مگابایت است.
- آپلود فایل به ChatGPT آزمایشی است؛ باید ظاهرشدن پیوست را در کادر گفتگو تأیید کنی.
- تغییرات رابط ChatGPT ممکن است قابلیت تشخیص خودکار پاسخ‌ها را مختل کند.
- مرورگر ممکن است پس از راه‌اندازی مجدد، مجوز دسترسی پوشه را دوباره درخواست کند.
- این پروژه وابسته یا مورد تأیید رسمی OpenAI یا Microsoft نیست.
